# آزادی نتورک | Azadi Network

وب‌سایت فول‌استک خدمات و تجهیزات شبکه — بدون هیچ وابستگی (Zero Dependency)، سازگار با تمام نسخه‌های Node.js از نسخه ۱۲ به بالا.

## امکانات

- فرانت‌اند و بک‌اند کامل با Node.js خام (بدون نیاز به npm install)
- تم دارک پیش‌فرض + تم روشن، کاملا راست‌چین و ریسپانسیو
- انیمیشن شبکه در هیرو، استوری‌ها، فروشگاه، نمونه کارها، مقالات، صفحه تماس
- پنل مدیریت کامل در مسیر `/admin` (مدیریت محتوا، محصولات، مقالات، نمونه کارها، رسانه، بکاپ و بازگردانی، تنظیمات)
- ردیابی بازدیدکنندگان و داشبورد CRM با داده‌های واقعی
- امنیت: محدودیت نرخ درخواست، هدرهای امنیتی و CSP سخت‌گیرانه، هش رمز عبور با scrypt، محافظت CSRF، محافظت از محتوا در برابر ذخیره و کپی

## ورود به پنل مدیریت

- مسیر: `/admin`
- نام کاربری: `prf`
- رمز عبور: `prf!123`

پس از اولین ورود حتما رمز عبور را از بخش تنظیمات تغییر دهید.

## نصب روی هاست cPanel

1. وارد cPanel شوید و به بخش **Setup Node.js App** بروید.
2. روی **Create Application** کلیک کنید.
3. تنظیمات را به این شکل وارد کنید:
   - **Node.js version**: هر نسخه‌ای (۱۲ به بالا)
   - **Application mode**: Production
   - **Application root**: پوشه‌ای که فایل‌ها را در آن آپلود می‌کنید (مثلا `azadinetwork`)
   - **Application URL**: دامنه یا زیردامنه مورد نظر
   - **Application startup file**: `app.js`
4. فایل‌های پروژه را با File Manager یا FTP در پوشه Application root آپلود کنید (یا فایل ZIP گیت‌هاب را Extract کنید).
5. نیازی به `npm install` نیست چون پروژه هیچ وابستگی‌ای ندارد.
6. روی **Restart** کلیک کنید. سایت بالا می‌آید.

داده‌ها (دیتابیس JSON، آپلودها و ردیابی) به صورت خودکار در پوشه `data/` کنار پروژه ساخته و ذخیره می‌شوند. برای تغییر مسیر ذخیره‌سازی متغیر محیطی `AZADI_DATA_DIR` را تنظیم کنید.

## اجرای محلی

```
node app.js
```

سایت روی پورت ۳۰۰۰ بالا می‌آید. برای تغییر پورت متغیر محیطی `PORT` را تنظیم کنید.

## استقرار روی Vercel

پروژه شامل `vercel.json` و `api/index.js` است و بدون تنظیم اضافه روی Vercel مستقر می‌شود.

توجه: فایل‌سیستم Vercel موقتی است؛ داده‌ها در `/tmp` ذخیره می‌شوند و ماندگار نیستند. نسخه Vercel برای پیش‌نمایش و دمو مناسب است. برای استفاده واقعی با ذخیره‌سازی دائمی، از هاست cPanel یا هر سرور Node.js استفاده کنید.
